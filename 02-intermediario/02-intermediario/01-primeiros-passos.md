# Módulo 01: Primeiros Passos

## Aula 01 - Apresentação Módulo TCP/IP Intermediário

Módulo focado em aprofundar os conceitos do básico, com foco em prática: laboratórios simulados, comandos reais de configuração de rede e entendimento mais técnico de switches, roteadores e VLANs.

## Aula 02 - Revisão TCP/IP Básico - Conceitos importantes para o Módulo TCP/IP Intermediário

Antes de avançar, é importante ter consolidado: modelo OSI e TCP/IP, endereçamento IPv4 (classes, CIDR, máscara), função de switch x roteador, e o papel do DHCP. Esses conceitos são a base para entender os laboratórios práticos que vêm a seguir.

## Aula 03 - Instalação eNSP

O **eNSP** (Enterprise Network Simulation Platform) é um software gratuito da Huawei usado para simular redes e praticar configurações em equipamentos virtuais (roteadores e switches), sem precisar de hardware físico.

## Aula 04 - Instalação EVE-NG

O **EVE-NG** (Emulated Virtual Environment - Next Generation) é uma plataforma de emulação de redes mais robusta, que permite simular ambientes com equipamentos de diferentes fabricantes (Cisco, Huawei, Mikrotik, etc.) em um único laboratório virtual.

## Aula 05 - Instalação Notepad++

O Notepad++ é um editor de texto leve usado para escrever e organizar configurações, scripts e anotações técnicas durante os laboratórios, sendo mais prático que o bloco de notas padrão do Windows.
